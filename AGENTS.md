# Project instructions

- Use English for source, comments, documentation and GitHub artifacts.
- Build the owner-approved Node.js signed-integer sum CLI with standard-library modules.
- Application behavior and acceptance criteria belong to the approved GitHub work item.
- Use native node:test for unit checks and real subprocess CLI E2E.
- Keep the configured unit and E2E commands independently runnable.
- Document the approved CLI arguments, output and exit codes in the README.
- Do not treat absent application code or zero executed cases as passing verification.
